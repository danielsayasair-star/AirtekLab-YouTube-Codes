## Proyecto

En este capítulo incorporamos un servidor web al sistema de monitoreo de temperatura.

El proyecto utiliza:

- ESP32
- Sensor DS18B20
- LCD 16x2 I2C
- WiFi
- Servidor Web
- Monitor Serie

La página web muestra la temperatura actual medida por el ESP32.

## Archivo

### ESP32

`SMT_WiFi_Cap4.ino`

Código utilizado en el proyecto.

## Importante

Antes de cargar el código debes completar tus propios datos de WiFi:

- Nombre de la red
- Contraseña

Las credenciales reales utilizadas durante el desarrollo no se publican en GitHub.
