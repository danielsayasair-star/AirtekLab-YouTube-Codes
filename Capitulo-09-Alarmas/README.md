## Proyecto

Sistema de monitoreo de temperatura con:

- ESP32
- Sensor DS18B20
- LCD I2C
- WiFi
- Google Sheets
- Google Apps Script
- Estados NORMAL, PREALARMA y ALARMA
- Alertas por email

## Archivos

### ESP32

Código completo del ESP32 utilizado en el proyecto.

### Google Apps Script

Código para recibir los datos en Google Sheets y gestionar las alertas por email.

## Importante

Los archivos publicados son versiones preparadas para compartir. Las credenciales reales del proyecto de Airtek Lab fueron reemplazadas por valores de ejemplo.

Antes de usar el código debes completar tus propios datos de WiFi, la URL de tu aplicación web de Google Apps Script y el email que recibirá las alertas.

Para entender la configuración y el funcionamiento paso a paso, consulta el video de este capítulo.

## Uso

Puedes descargar o copiar los códigos y utilizarlos en tu propio proyecto. Las modificaciones se realizan en tu propio entorno de desarrollo.
