📺 **Ver el capítulo en YouTube:**

## Proyecto

En este capítulo incorporamos la conexión WiFi al sistema de monitoreo de temperatura.

El proyecto utiliza:

- ESP32
- Sensor DS18B20
- LCD 16x2 I2C
- WiFi
- Monitor Serie

## Archivo

### ESP32

`SMT_WiFi_Cap3.ino`

Código utilizado en el proyecto.

## Importante

Antes de cargar el código debes completar tus propios datos de WiFi:

- Nombre de la red
- Contraseña

## Uso

Puedes descargar o copiar el código y utilizarlo en tu propio proyecto.

Las modificaciones se realizan en tu propio entorno de desarrollo.

Los códigos de este repositorio corresponden a los proyectos mostrados en el canal **Airtek Lab**.
