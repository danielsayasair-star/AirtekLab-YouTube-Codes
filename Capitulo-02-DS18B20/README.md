📺 **Ver el capítulo en YouTube:**

## Proyecto

En este capítulo reemplazamos la temperatura simulada del Capítulo 1 por una medición real utilizando un sensor DS18B20.

El proyecto utiliza:

- ESP32
- Sensor DS18B20
- LCD 16x2 I2C
- Librería `OneWire`
- Librería `DallasTemperature`
- Monitor Serie

## Archivo

### ESP32

`SMT_WiFi_Cap2.ino`

Código utilizado en el proyecto.

Puedes descargar o copiar el código y utilizarlo en tu propio proyecto.
