📺 **Ver el capítulo en YouTube:**

## Proyecto

En este capítulo conectamos el sistema de monitoreo de temperatura con Google Sheets.

El ESP32 envía periódicamente:

- Fecha
- Hora
- Temperatura

Google Apps Script recibe los datos y los agrega a la hoja de cálculo.

## Archivos

### ESP32

`SMT_WiFi_Cap6.ino`

Código utilizado en el ESP32.

### Google Apps Script

`Code.gs`

Código utilizado para recibir los datos y guardarlos en Google Sheets.

## Importante

Los archivos publicados son versiones preparadas para compartir. Las credenciales reales del proyecto de Airtek Lab fueron reemplazadas por valores de ejemplo.

Antes de usar el código debes completar tus propios datos de:

- WiFi
- URL de tu aplicación web de Google Apps Script
