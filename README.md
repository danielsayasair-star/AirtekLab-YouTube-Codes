## Importante

Los archivos publicados son versiones preparadas para compartir. Las credenciales reales del proyecto de Airtek Lab fueron reemplazadas por valores de ejemplo.

Antes de usar los códigos debes completar tus propios datos cuando corresponda, como:

- WiFi
- URL de Google Apps Script
- Credenciales o token de servicios utilizados en el proyecto
- Dirección de email para las alertas

Consulta el README de cada capítulo y el video correspondiente para la configuración paso a paso.

## Uso

Puedes descargar o copiar los códigos y utilizarlos en tu propio proyecto. Las modificaciones se realizan en tu propio entorno de desarrollo.

Los códigos de este repositorio corresponden a los proyectos mostrados en el canal **Airtek Lab**.
