# Airtek Lab - YouTube Codes

Códigos y recursos de los proyectos de electrónica, ESP32 e IoT del canal Airtek Lab.

📺 **Canal de YouTube:**  
https://www.youtube.com/@AirtekLab

## Capítulos

Los códigos están organizados por capítulo del canal.

### Capítulo 9 - Alarmas

Proyecto de monitoreo de temperatura con:

- ESP32
- Sensor DS18B20
- LCD I2C
- WiFi
- Google Sheets
- Google Apps Script
- Estados NORMAL, PREALARMA y ALARMA
- Alertas por email

Los archivos publicados son versiones preparadas para compartir. Las credenciales reales del proyecto de Airtek Lab fueron reemplazadas por valores de ejemplo.

Antes de usar el código debes completar tus propios datos de WiFi, la URL de tu aplicación web de Google Apps Script y el email que recibirá las alertas.

Consulta el video correspondiente para la configuración paso a paso.

## Uso

Puedes descargar o copiar los códigos y utilizarlos en tu propio proyecto. Las modificaciones se realizan en tu propio entorno de desarrollo.

Los códigos de este repositorio corresponden a los proyectos mostrados en el canal **Airtek Lab**.
