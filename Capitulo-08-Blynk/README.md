## Proyecto

En este capítulo incorporamos Blynk al sistema de monitoreo de temperatura.

El proyecto utiliza:

- ESP32
- Sensor DS18B20
- LCD 16x2 I2C
- WiFi
- Blynk
- Servidor Web

La temperatura se envía a Blynk en la primera medición y luego solamente cuando cambia.

## Archivo

### ESP32

`SMT_WiFi_Cap8.ino`

Código utilizado en el proyecto.

## Importante

Antes de cargar el código debes completar tus propios datos de:

- WiFi
- Blynk Template ID
- Blynk Template Name
- Blynk Auth Token

Las credenciales reales del proyecto de Airtek Lab no se publican en GitHub.
