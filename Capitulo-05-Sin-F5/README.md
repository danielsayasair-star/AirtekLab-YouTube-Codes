# Capítulo 5 - Actualiza la Temperatura en tu Página Web SIN F5

📺 **Ver el capítulo en YouTube:**

https://youtu.be/sn9wpc-gSpE

## Proyecto

En este capítulo modificamos la página web del ESP32 para actualizar la temperatura automáticamente sin recargar la página.

El proyecto utiliza:

- ESP32
- Sensor DS18B20
- LCD 16x2 I2C
- WiFi
- Servidor Web
- JavaScript
- Monitor Serie

La página consulta periódicamente el valor actual de temperatura y lo actualiza sin necesidad de presionar F5.
