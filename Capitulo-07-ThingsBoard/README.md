## Proyecto

En este capítulo incorporamos ThingsBoard al sistema de monitoreo de temperatura.

El proyecto utiliza:

- ESP32
- Sensor DS18B20
- LCD 16x2 I2C
- WiFi
- ThingsBoard
- MQTT
- Servidor Web

La temperatura se envía a ThingsBoard cuando cambia respecto del último valor enviado.

## Archivo

### ESP32

## Importante

Antes de cargar el código debes completar tus propios datos de WiFi y el token de acceso de tu dispositivo en ThingsBoard.
